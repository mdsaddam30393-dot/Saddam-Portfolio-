# MD. Saddam Hossain — Portfolio

A lightweight, Vercel-ready personal portfolio website.

## Files
- `index.html` — website content
- `styles.css` — responsive design
- `script.js` — menu, scroll progress and reveal animations
- `assets/profile.png` — profile image

## Deploy on Vercel
### Option 1 — GitHub
1. Create a new GitHub repository.
2. Upload all files and the `assets` folder.
3. Go to Vercel and choose **Add New → Project**.
4. Import the GitHub repository.
5. Framework preset: **Other**
6. Build command: leave empty.
7. Output directory: `.`
8. Click **Deploy**.

### Option 2 — Vercel CLI
Install Vercel CLI, then from this folder run:
`vercel`

## Before publishing
- Add your LinkedIn URL in the Contact section.
- Add your actual CV PDF and change the Email/CTA button to a CV download link if desired.
- Add verified certificate files/links if you want visitors to view them.
- Keep company-confidential shipment information out of the public portfolio.
